已確認舊 v3 雲端目前只有 10 筆，因此手機的舊 localStorage 曾先建立雲端。

- 保留 v11.1 的照片壓縮、照片顯示、SOS、完整資料同步。

部署後：
1. 關閉手機網站分頁。
2. 先用有 13 筆的電腦開網站，等 5 秒。
3. 開 /api/state，確認 items 有 13 筆。
4. 再開手機。
